# Base44 development notes

- This is a React Native client, not a web/API server. No backend or external credentials are implemented/required by the current source; README service claims are aspirational.
- Commit `f157624c353c316a6ef7ca2b8cd79d04ecf521f3` is already included in this branch. The notification import `notifcation.styles` is intentionally misspelled to match the real filename; the deleted `notification.styles.ts` was empty, not the missing implementation.
- The pinned Yarn 3.6.4 originally had a Yarn v1 lockfile, so immutable installs failed with YN0028. The lockfile is now migrated. Use Corepack/Yarn, not the stale package-lock.json. Compose installs dependencies immutably into its named volume before starting the source-mounted Vite server.
- React Navigation native/bottom-tabs/stack must share major version 7, with react-native-screens explicitly installed. Screens is pinned to 4.9.0: newer releases resolved by a caret failed native code generation with `Unknown prop type for onAttached`. Babel/Metro/TypeScript config and CLI are aligned to React Native 0.79.2.
- Browser preview reuses App.tsx and all original screens via react-native-web. Only Vite resolves the gradient adapter and image-picker's existing browser implementation. Native entry/config remain separate. Vite resolves `.web` files first, uses the vector-icons dist builds/fonts, and converts static image requires to browser asset imports. The browser global alias is required by gesture-handler.
- Start: `docker compose -f docker-compose.base44.yml up -d --build`. Port 3000 must serve `/@vite/client` and `/index.web.tsx`, not a dist bundle. The platform's additional Vite host allowlist is passed through Compose; do not hardcode sandbox hosts.
- Verify: `docker compose -f docker-compose.base44.yml exec -T web yarn build:web`, `yarn tsc --noEmit`, and `yarn test --runInBand` inside the web container. Jest transforms native/navigation packages, mocks native gradients and gestures, and unmounts the renderer/clears animation timers to avoid teardown crashes.
- Native JS bundle check (not an APK/emulator test): `yarn react-native bundle --platform android --dev true --entry-file index.js --bundle-output /tmp/car-android.bundle --assets-dest /tmp/car-native-assets` inside the container.
- Independent browser verification passed at 390x844 and 1440x900: Home renders, notification tab shows six entries, message row opens ChatScreen, back navigation returns home, no runtime/request errors or broken visible images. Base44 screenshot capture was unavailable because its preview panel was hidden; do not claim visual screenshot verification from these checks.
